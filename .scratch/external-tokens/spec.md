# 外部提供的令牌与外部消费者

Status: done

## 场景（对应 REQUIREMENTS.md 的 R-157 / R-158；写不出这一节的需求先不做）

- **令牌由运行时提供（宿主不拥有主题）时**：设计令牌由主题运行时 / 组件库在运行时注入，本仓全局样式与
  组件样式里写 `var(--ext-color-primary)`，本地 CSS 查不到定义 → D04 报「未定义的令牌引用：--ext-color-primary」。
  **现在**：只能对整片样式目录写 `exceptions`，把**真正的**悬空引用也一起关掉，而且这类目录会越写越宽。
- **令牌定义在本包、消费者在别的包（或非契约域）时**：`tokens/scale.css` 里定义的 `--app-len-*` 被
  workspace 另一个包的组件样式引用；本包的契约域只看 `src/**`，那些消费者文件不在 `records` 里
  → D05 把 `--app-len-*` 报成「死令牌」。**现在**：只能对那份令牌文件写 `exceptions`，把本包内真死的令牌也一起放过。
- **现在拦不拦得住**：拦不住。两种场景都只能"整片豁免"；豁免一写，真正的违规就跟着静默了。

## 背景与问题

令牌模型只有两态：「本仓定义」与「不拥有」。宿主把主题交给运行时（或把令牌表拆到别的包）时，
D04（引用闭合）、D05（无死令牌）都会对着**正确写法**报错。`exceptions` 是唯一的宽松通道，
但它是「某条规则对某类文件不适用」的粒度 —— 对"某**前缀**是外部提供的"、"某**目录**是本包的消费者"
这两件事都太宽：豁免按目录写，目录里未来的真违规一并静默。

## 目标

- `designSystem({ externalTokens })`：声明外部运行时提供的令牌**命名空间**（前缀 + 提供方）。
  D04 对这些前缀的 `var()` 引用视为闭合；D05 不把外部前缀的令牌算进死令牌账。
- `designSystem({ externalConsumers })`：声明本包之外（或契约域之外）会消费本包令牌的文件 glob。
  D05 只读这些文件、把其中出现的令牌名算作「被引用」，不引入跨包图、不改扫描根。
- 配置期 fail-closed：形状不对（前缀不以 `--` 开头、重复前缀、空 glob）在 `designSystem()` 调用时直接报错。
- 报告/文档可见：`--render-docs` 的 params 块与 `--explain` 能看到这两项声明；USAGE 补字段说明。

## 非目标

- **不做** R-50 的跨包全量语义（多根角色表 / 跨包统一退出码）；本项只补"跨包事实"这一小块。
- 不扫描 `node_modules`、不跟随任意深度的外部树（只按声明的 glob 找文件）。
- 不校验 `provider` 的版本 / 包是否真的装了 —— 那归宿主依赖管理。
- 不处理"外部令牌改名"的自动对账（由提供方升级暴露，不由本仓的本地表兜住）。

## 验收标准

- 夹具 `__fixtures__/external-tokens`：「违规必报 × 合规不报」两条都覆盖 ——
  - 未声明 `externalTokens` 时 D04 对 `var(--ext-*)` 报；声明后不报；
  - 本包内真实的悬空引用（既不在本地定义、也不在外部命名空间）**仍然报**；
  - `externalConsumers` 文件里引用的本包令牌**不报死令牌**；本包内确实没人用的令牌**仍然报**。
- 单测：`designSystem()` 的前缀/fail-closed 校验、`externalConsumers` 的 0 命中去重。
- `pnpm check` 全绿（含 `--self-test`；新增夹具后 `docs/ARCHITECTURE.md` 的夹具数同步）。

## 边界与取舍

- **前缀是字符串前缀匹配**：`--ext-` 会放行 `--ext-anything`；声明方自己负责别把过宽的前缀给出去。
- **`externalConsumers` 0 命中 = 声明未生效**：不静默降级，也不额外造 finding；此时 D05 与没声明时一样
  （该报的假死令牌照报）—— **宁可吵，不可静默放过**。报告侧靠 `declaration-no-match` 后续覆盖（另开需求）。
- **外部消费者只读文本**：只扫样式/脚本类扩展名，按令牌名出现算「被引用」；不做解析、不进图。
- 被否方案：`externalTokens` 收显式令牌**名单**。否掉的理由：运行时注入的令牌随主题包变化，
  名单会变成第二份真相；命名空间是提供方能承诺的最小事实。
